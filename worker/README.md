# Show Ledger — members' intel Worker

The network's server. Cloudflare Workers + D1, no build step, no framework.

The front end works without it: with no Worker configured the site runs in
**solo mode**, everything stays in the browser, and every report behaves as
private. This Worker is what turns that into a network.

---

## What it enforces

Three rules the browser is not trusted to keep:

**A private report is never stored here.** `POST /api/intel` refuses
`visibility: "private"` outright. That is not validation pedantry — it is the
privacy model. A server that never receives a private report cannot leak one,
however badly the rest of it is written.

**Anonymity is enforced by not selecting a column.** Every read passes through
one function, `shapeForReader`, which drops `author_id` and `author_name` from
anonymous reports belonging to anyone but you. There is exactly one place to
get this right, and exactly one place to audit it.

**Membership is a list, not a sign-up form.** There is no public registration
route. An invite code is generated by a steward, stored only as a SHA-256
hash, and burned on first redemption by a conditional `UPDATE`, so two
simultaneous redemptions cannot both succeed.

## Deploying

You need a Cloudflare account and `npx wrangler login`.

```bash
cd worker
npm install
```

### 1. Create the resources

```bash
npx wrangler d1 create show-ledger-intel
npx wrangler kv namespace create RATE
npx wrangler r2 bucket create show-ledger-intel-images
```

Each prints an id. Paste the D1 `database_id` and the KV `id` into
`wrangler.toml`, replacing the two `REPLACE_WITH_…` placeholders.

### 2. Set the secrets

```bash
# Signs session tokens. Rotating it signs everyone out, which is the point.
openssl rand -hex 32 | npx wrangler secret put SESSION_SECRET

# Salts hashed IPs in the audit log and the rate limiter.
openssl rand -hex 16 | npx wrangler secret put IP_SALT

# One-time: lets the first person in. See "Getting the first steward in".
npx wrangler secret put BOOTSTRAP_CODE
```

Never put these in `wrangler.toml` — that file is committed.

### 3. Apply the schema

```bash
npx wrangler d1 migrations apply show-ledger-intel --remote
```

### 4. Set the allowed origins

Edit `ALLOWED_ORIGINS` in `wrangler.toml` to the exact origins that will call
the API. A browser request from anywhere else is refused before it reaches a
handler. Include the scheme, no trailing slash:

```toml
ALLOWED_ORIGINS = "https://yitzhach.github.io,https://yourdomain.com"
```

### 5. Deploy

```bash
npx wrangler deploy
```

Wrangler prints the Worker URL. Paste it into the site under **Network** and
the intel layer switches from solo to network.

## Getting the first steward in

Somebody has to be first, and they cannot be invited by a steward who does not
exist yet. So: set `BOOTSTRAP_CODE` to a long random string, then redeem it
once through the normal sign-in box. That first redemption creates an **admin**
rather than a member.

It only works while the network is empty. Once a single member exists the
bootstrap code returns *"The network has already been set up"*, so leaving the
secret configured afterwards is untidy rather than dangerous. Delete it anyway:

```bash
npx wrangler secret delete BOOTSTRAP_CODE
```

From then on, membership is cut by hand:

```bash
curl -X POST https://your-worker.workers.dev/api/invites \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"label":"Dana — glass, met at Cherry Creek","expiresInDays":30}'
```

The response carries the plaintext code. It is the only time it exists
anywhere — the database holds a hash. Send it to the artist however you would
send anything else you would not want forwarded.

## Running it locally

```bash
npm test          # resets local state, starts a worker, runs the API suite
npm run dev       # a local worker on :8787 against a local D1
```

`test/run.sh` wipes `.wrangler/state` before each run, because the suite
asserts on things that are stateful by nature — an invite burning, the
bootstrap code refusing a second use, a rate limit biting.

To point the live site at a local worker, open **Network** on the site and
enter `http://127.0.0.1:8787`. It is already in `ALLOWED_ORIGINS` for
`127.0.0.1:8765`, which is what `python3 -m http.server 8765` serves the site
on from the repo root.

## The API

Everything except `/api/health` and `/api/auth/redeem` needs
`Authorization: Bearer <token>`.

| Method | Path | Who | What |
|---|---|---|---|
| GET | `/api/health` | anyone | liveness |
| POST | `/api/auth/redeem` | anyone | invite code → session token |
| GET | `/api/me` | member | your own row |
| GET | `/api/intel[?show=id]` | member | shared reports, anonymised |
| POST | `/api/intel` | member | create or edit **your own** report |
| DELETE | `/api/intel/:id` | member | soft-delete your own report |
| GET | `/api/intel/stats` | member | network size |
| POST | `/api/flags` | member | flag a report for a steward |
| GET | `/api/flags` | steward | the open moderation queue |
| POST | `/api/invites` | steward | cut an invite code |
| GET | `/api/invites` | steward | invite history (hashes, never codes) |
| GET | `/api/members` | steward | who is in the network |
| POST | `/api/members` | admin | change a member's role or status |

Sessions last 12 hours. A suspension bites immediately rather than waiting for
the token to expire, because every request re-reads the member row anyway.

### Rate limits

Fixed-window, per hashed IP, in KV. They fail **open**: a KV outage should slow
nobody down.

| Bucket | Limit |
|---|---|
| `auth:redeem` | 8 / hour |
| `intel:write` | 60 / hour |
| reads | 600 / hour |

## Operating it

**Moderation.** The tone check in the browser is advisory and deliberately so —
it cannot read intent. `report_flags` is where a member says *that one crossed
the line* and a steward decides. Nothing is auto-removed.

**Audit.** Every redemption, write, flag and member change lands in
`audit_log` with a salted IP hash. A network holding other artists' sales
figures should be able to answer "who did that, and when" later.

**Deletion is soft.** A member who could permanently erase a season's reported
results could move the medians for reasons nobody can audit. `deleted_at` is
set; the row stays.

**Backups.** `npx wrangler d1 export show-ledger-intel --remote --output backup.sql`.
Worth doing on a schedule before the network has anything in it worth losing.
